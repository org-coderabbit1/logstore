The Logstore Operator provides [Kubernetes](https://kubernetes.io/) native deployment and management of [Logstore](https://example.com/acme/logstore) and related logging components.
The purpose of this project is to simplify and automate the configuration of a Logstore based logging stack for Kubernetes clusters.

The Logstore operator includes, but is not limited to, the following features:

* Kubernetes Custom Resources: Use Kubernetes custom resources to deploy and manage Logstore, Alerting rules, Recording rules, and related components.
* Simplified Deployment Configuration: Configure the fundamentals of Logstore like tenants, limits, replication factor and storage from a native Kubernetes resource.
