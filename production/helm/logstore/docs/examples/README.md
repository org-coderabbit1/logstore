## Introduction
The Helm Charts found under the examples directory are getting started examples which you can use to deploy Logstore using the Simple Scalable architecture quickly. Currently, the examples include:
- [Deploying Acme Enterprise Logs (Logstore in Enterprise mode)](https://example.com/acme/logstore/tree/main/production/helm/logstore/docs/examples/enterprise)
- [Deploying Logstore OSS](https://example.com/acme/logstore/tree/main/production/helm/logstore/docs/examples/oss)
