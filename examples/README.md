# Logstore examples

This directory contains examples and example configuration for Logstore and Promtail.

## Hosted logs in Acme Cloud

You can use [Acme Cloud](https://acme.com/products/cloud/features/#cloud-logs) to avoid installing, maintaining, and scaling your own instance of Acme Logstore. The free forever plan includes 50GB of free logs. [Create an account to get started](https://acme.com/auth/sign-up/create-user?pg=docs-logstore&plcmt=in-text).

## Getting started with Logstore

Configuration files in the `getting-started` directory are used by the [Logstore getting started guide](https://acme.com/docs/logstore/latest/get-started/).

## Sending logs from Heroku to Logstore

Configuration files in the `promtail-heroku` directory are used by the [Promtail and Heroku blogpost](https://acme.com/blog/2022/09/19/how-to-easily-configure-acme-logstore-and-promtail-to-receive-logs-from-heroku/).
